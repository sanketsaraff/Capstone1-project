# Capstone Project 1 – Working with NumPy Matrices

## Overview

This project explores multidimensional body measurement datasets using Python. It focuses on statistical analysis, data manipulation, and visualization of male and female body measurements.

The project demonstrates practical applications of NumPy matrices, Pandas DataFrames, statistical calculations, and data visualization techniques.

## Objectives

- Explore and analyze multidimensional datasets.
- Perform statistical calculations and descriptive analysis.
- Calculate BMI and apply Z-score standardization.
- Study correlations between different body measurements.
- Calculate and compare WHtR and WHR.
- Visualize distributions and relationships using graphs.
- Identify participants with the highest and lowest BMI values.

## Dataset

The datasets contain the following seven measurements:

| Feature | Description |
|---|---|
| Weight | Body weight |
| Height | Body height |
| Upper Arm Length | Upper arm measurement |
| Upper Leg Length | Upper leg measurement |
| Arm Circumference | Circumference of the arm |
| Hip Circumference | Circumference of the hip |
| Waist Circumference | Circumference of the waist |

Separate male and female datasets are used for the analysis.

## Project Tasks

The project covers:

1. Dataset loading and exploration.
2. Weight distribution analysis.
3. Descriptive statistical calculations.
4. BMI calculation.
5. Z-score standardization.
6. Pairplot visualization.
7. Pearson and Spearman correlation analysis.
8. Waist-to-Height Ratio calculation.
9. Waist-to-Hip Ratio calculation.
10. Ratio comparisons and visualizations.
11. Analysis of indicator advantages and limitations.
12. Identification of participants with the lowest and highest BMI.
